## About

A clean, responsive portfolio built with React and Vite, deployed on Vercel. The site presents my projects, tech stack, and contact information for internship and job opportunities.

## Tech Stack

- React 19
- Vite
- TailwindCSS
- Vercel (deployment)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
